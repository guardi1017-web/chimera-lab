## 1. 한 줄 요약
네크로맨서가 최대 3마리의 키메라에게 적의 시체(혼)를 먹여 유전자와 스킬을 중첩시키고, 잡몹 시체를 과식해 폭주 직전인 키메라를 적진에 **자폭(탈피)**시켜 위기를 뒤집고 **남겨진 심장 코어로 즉시 고등급 키메라를 재연성**하는 실시간 액션 게임.

## 2. 5차 실험판 폐기 사유 및 리부트 핵심 변경점
1. **[조작 변경] 소환수 2번 찍기 폐기 → <시체(혼) 자석 흡수 & 스와이프 투척>:** 이동 중 작은 소환수 둘을 찍는 조작은 위기 시 불가능하다. 이제 바닥의 '혼'에 다가가면 시간이 느려지며 먹일 대상이 자동 연결된다.
2. **[합성 변경] 30종 고정 등급표 폐기 → <유전자 비율 누적 & 스킬 교배>:** 부모와 무관한 무작위 결과는 키메라를 만드는 맛이 없다. `맹수/갑주/사수` 유전자 누적 개수에 따라 외형(파츠)과 스킬이 실시간으로 진화한다.
3. **[교착 해결] 동등급 합성 제한 폐기 → <상시 흡수 성장 + 시체 품질별 불안정도>:** `[3, 2, 1]` 등급으로 슬롯이 막히는 문제를 없앤다. 어떤 등급의 혼이든 기존 키메라에게 먹여 체급을 올릴 수 있다.
4. **[핵심 재미] MP 부활비 폐기 → <불안정도(폭주)와 탈피(Core Molting)>:** 잡몹 시체를 막 먹이면 '불안정도'가 차올라 자폭하지만, 터진 자리에 **등급과 유전자를 보존한 '변이 코어(심장)'**가 남아 화력 공백 없이 더 강한 괴물로 즉시 부활한다. 엘리트 시체를 먹이면 불안정도가 0%로 정화된다.

## 3. 6차 핵심 규칙 (`src/sim.js` 구현 명세)

### 3.1 조작과 슬로우 모션 (One-Thumb Control)
- **평상시 이동:** 화면을 누르고 끌면(Drag) 네크로맨서가 움직인다.
- **빈 슬롯이 있을 때 (소환수 < 3):** 바닥의 혼 반경 안에 들어가면 즉시 기본 1등급 소환수로 되살아난다 (MP 소모 없음).
- **슬롯이 꽉 찼을 때 (소환수 == 3, 흡수 합성):**
  - 바닥의 혼 반경(흡수 범위)에 진입하면 **게임 속도가 0.25배(슬로우)로 느려진다.**
  - 가장 가까운(혹은 마지막으로 지정한) 내 키메라와 바닥의 혼 사이에 **예고 연결선**이 표시된다.
  - 그대로 혼을 밟으면 연결된 키메라가 해당 혼을 즉시 흡수(합성)한다.
- **수동 자폭(도축) 스위치:** 화면을 **더블 탭(또는 짧은 스와이프)**하면, 현재 불안정도가 가장 높은(혹은 가장 등급이 낮은) 키메라가 가장 가까운 적 무리에게 돌진해 즉시 **자폭(탈피)**한다.

### 3.2 유전자 누적과 스킬 교배 (Chimera Genetics)
- 모든 혼은 3가지 유전자 타입 중 하나를 가진다: **맹수(Red/삼각형), 갑주(Blue/사각형), 사수(Green/원).**
- 키메라 객체는 자신의 누적 유전자 배열/카운트를 가진다: `genes: { beast: 1, armor: 0, ranger: 2 }`
- **체급(등급) 결정:** 총 흡수한 유전자 가치 합산에 따라 등급(Level 1~10)과 덩치, 기본 체력/공격력이 상승한다.
- **주력 스킬 (가장 높은 비율의 유전자에 의해 결정):**
  - **맹수 중심:** `[피의 도약]` 쿨타임마다 적에게 도약해 물어뜯고 출혈 부여.
  - **갑주 중심:** `[고통의 반격]` 주변 적 도발 + 피격 횟수 누적 시 주변 충격파 넉백.
  - **사수 중심:** `[일제 사격]` 원거리에서 부채꼴 뼈 화살 연사.
- **부유전자 개조 (섞인 다른 유전자 개수 1개당 주력 스킬 변형):**
  - `+ 맹수 섞임`: 스킬 쿨타임 감소, 이동/공격 속도 증가, 공격 시 흡혈/출혈 추가.
  - `+ 갑주 섞임`: 투사체/충격파에 강한 **넉백(밀치기)** 및 기절 부여, 체력/방어력 급증.
  - `+ 사수 섞임`: 근접/충격파 스킬 사용 시 **사방으로 추가 투사체(뼈 파편/검풍) 발사**.

### 3.3 시체 품질과 불안정도 (Instability & Molting)
키메라마다 `instability` (0 ~ 100%) 수치를 가진다.

| 혼(시체) 등급 | 드롭 몬스터 | 흡수 시 성장치 | 불안정도 변화 | 시각 표현 (`render.js`) |
|---|---|---|---|---|
| **불량 혼 (1등급)** | 일반 잡몹 | 유전자 +1 | **+30% 급증** | 작은 회색/붉은 혼 |
| **신선한 혼 (2등급)** | 중형 몬스터 (18초~) | 유전자 +2, 체력 50% 회복 | **+15% 증가** | 중간 크기 푸른빛 혼 |
| **순혈 코어 (3등급+)** | **돌격병 / 엘리트 (20초 주기)** | 유전자 +3, **특수 변이 부여** | **0%로 완전 초기화(안정화!)** | 크고 빛나는 황금/보라색 코어 |

- **과부하(불안정도 80% 이상):** 키메라 몸체가 붉게 점멸하며 덜덜 떨린다. 공격력과 공격속도가 **1.5배 폭증(광기 상태)**한다.
- **폭주 및 탈피 폭발 (불안정도 100% 도달 또는 수동 더블 탭):**
  1. 키메라가 가장 밀집된 적진으로 튀어가 **대폭발**을 일으킨다 (반경 내 일반 적 즉사, 엘리트에게 큰 피해 + 넉백).
  2. 폭발 자리에 해당 키메라의 **<변이 심장(Core)>**이 떨어진다 (유지 시간 12초).
  3. **코어 계승 (화력 공백 방지):** 네크로맨서가 이 <변이 심장>을 밟으면, **폭발 전 키메라의 등급(유전자 총량 80~100%)을 그대로 보존하고 불안정도만 0%로 초기화된 새 키메라**가 즉시 부활한다.

### 3.4 90초 웨이브와 리듬 설계
- **0~19초 (빌드업):** 1등급 적 등장. 플레이어는 3마리 슬롯을 채우고, 1마리에게 불량 혼을 몰아 먹여 불안정도 80~90%(폭탄 상태)를 만든다.
- **20초 / 45초 / 70초 (사냥꾼 돌격 - 위기와 기회):**
  - 화면 끝에 붉은 경고선(`!`)이 1.5초간 뜬 뒤, 네크로맨서를 향해 **엘리트 돌격병**이 무서운 속도로 들이받는다.
  - **대처법 A:** 갑주 유전자 키메라로 길을 막아 충돌을 받아낸다 (1등급은 튕겨 나가고 2등급 이상 갑주는 버팀).
  - **대처법 B:** 불안정도가 꽉 찬 키메라를 돌격병 면전에 **자폭(탈피)**시켜 한 방에 제압한다.
  - **보상:** 돌격병 처치 시 떨어지는 **<순혈 코어>**를 주력 키메라에게 먹여 불안정도를 0%로 식히고 영구 보존(에이스화)한다.

## 4. 화면 및 사운드 연출 (`src/render.js` & Web Audio)

### 4.1 시각적 직관성 (외형 조립)
- 30종을 개별로 그리지 않고 **절차적 도형 조립(Procedural Parts)**으로 렌더링한다.
- 중심 코어 도형(주 유전자: 삼각형/사각형/원) 주변에, 흡수한 부유전자 개수만큼 **가시(맹수), 방패 장갑판(갑주), 포신/눈알(사수)** 도형이 다닥다닥 들러붙어 덩치가 커진다.
- 불안정도가 높을수록 몸체 색상이 붉게 달아오르고 진동(Shake) 진폭이 커진다.

### 4.2 필수 프로시저럴 효과음 (Web Audio API — 외부 에셋 없이 코드로 생성)
1. **혼 흡수음:** 짧고 경쾌하게 피가 빨려 들어가는 낮은 주파수 스윕 (`150Hz -> 400Hz`, 0.08초).
2. **과부하 경고음:** 불안정도 80% 돌파 시 심장 박동 같은 둔탁한 비트음.
3. **탈피 대폭발음:** 화이트 노이즈 + 저음 붐(`80Hz -> 30Hz`, 0.3초) + 화면 흔들림(Screen Shake).
4. **돌격병 예고음:** 20초 엘리트 등장 시 날카로운 사이렌 비프음.

   - 기존 동등급 합성 및 MP 제한 로직 제거.
   - 키메라 엔티티에 `genes: { beast, armor, ranger }` 및 `instability (0~100)` 상태값 추가.
   - 슬롯 3개 만석 시 혼 접근 슬로우(0.25x) 및 즉시 흡수 로직 구현.
   - `instability >= 100` 도달 시 광역 폭발 데미지 처리 후, 자리에 `InheritedCore(유전자 보존 아이템)` 드롭 로직 구현.
   - 20초 주기 엘리트 돌격병 스폰 및 처치 시 `PureCore(불안정도 0 초기화)` 드롭 구현.
2. **`src/render.js` 개편:**
   - 유전자 카운트 기반 다중 도형 결합 렌더링(몸통 + 파츠 부착) 구현.
   - 불안정도 게이지(또는 붉은 점멸/진동 연출) 및 슬로우 모션 시 흡수 연결선 시각화.
   - Web Audio API 기반 기본 효과음 4종 합성기(Synthesizer) 유틸리티 추가.
3. **검증 기준:**
   - 봇 시뮬레이션보다 **실제 폰 터치 플레이 시 첫 30초 안에 "잡몹 먹여 불리기 → 돌격병 등장 → 자폭으로 폭사시키기 → 떨어진 심장 주워 즉시 재연성" 루프가 한 손가락으로 매끄럽게 돌아가는지** 확인한다.
